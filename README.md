# Statis

A single-page calculator with nine tabs:

- **Contingency table** — chi-squared test (with optional Yates' continuity correction), Fisher's exact test, and odds ratio / relative risk with 95% confidence intervals. An "Add to Meta-Analysis" button sends the current 2×2 table straight into the Meta-Analysis tab's study list.
- **Pivot** — upload or paste a CSV/TSV, assign each column's scale of measurement (continuous, ordinal, or nominal, auto-detected from the data), and get a single-variable summary (mean/SD/SEM/median/IQR with a mini histogram for continuous variables; a frequency table with a mini bar chart, and cumulative counts for ordinal, for categorical ones) plus a filterable row × column cross-tabulation (toggle any category on/off, and switch cell values between count, % of row, % of column, and % of total). Automatically picks and runs the appropriate association test — Pearson's chi-squared (with Yates' correction shown for 2×2), Fisher's exact test for a 2×2 table with small expected counts, or the Fisher–Freeman–Halton exact test (the same idea generalized to any table size) — based on Cochran's criteria, and reports Cramér's V plus odds ratio / relative risk for 2×2 tables. The Fisher–Freeman–Halton implementation is validated in this app by confirming it exactly reproduces the 2×2 Fisher's exact result; it falls back to the chi-squared approximation (clearly labeled) for tables too large to enumerate exactly in the browser.
- **T-test** — independent-samples or paired t-tests, with a Shapiro–Wilk normality check (validated for, and restricted to, 3–5,000 observations — outside that range a value is deliberately not shown rather than presenting an unreliable approximation), per-group histograms, and (for independent samples) a Levene's test for equal variance. A Method selector defaults to Auto, picking Student's t-test, Welch's t-test, Mann–Whitney U, or the Wilcoxon signed-rank test based on those checks — or you can override it manually. Also shows a bar chart of group means with 95% CI error bars, a full descriptive stats table (mean, SD, SEM, CI, median, mode, quartiles, IQR), and an effect size with an interpretation guide: Cohen's d for the t-tests, rank-biserial correlation for Mann–Whitney U, and — a distinct, non-interchangeable statistic, labeled as such — z⁄√n for the Wilcoxon signed-rank test.
- **Correlation** — a scatter plot, Shapiro–Wilk normality checks on X and Y, and a linearity (curvature) test, feeding an Auto method selector that picks Pearson's r or Spearman's rank correlation. Kendall's tau is available as a manual third option, suggested (not auto-applied) when the sample is small and either variable has tied values. Also fits an OLS linear regression, with Breusch–Pagan and residual-normality diagnostics that flag when the regression's own assumptions don't hold.
- **Survival** — Kaplan–Meier estimation for one group or a two-group comparison, from pasted or CSV-uploaded time/event/group data with column mapping, row-level validation, and a data-quality summary. Reports the survival curve (with Greenwood log-log confidence bands and censoring ticks), median survival with 95% CI (explicitly "not reached" when applicable, never approximated), a two-sided log-rank test for two groups, an inspectable life table, and export to SVG/PNG/CSV, clipboard, and a generated Methods-and-Results paragraph. No hazard ratio is computed — that needs a Cox model, which isn't implemented yet.
- **ANOVA** — an arbitrary number of groups (add/remove as needed), with per-group Shapiro–Wilk normality checks, histograms, and a k-group Levene's test. A Method selector defaults to Auto, which picks standard one-way ANOVA (normal groups, equal variances), Welch's ANOVA (normal groups, unequal variances), a Box–Cox transform followed by Welch's ANOVA (non-normal groups that a transform fixes), or the Kruskal–Wallis test (non-normal groups a transform can't fix, or any group with zero variance — every value identical — which Welch's ANOVA can't handle since it weights each group by 1/variance) — all four are also selectable manually, with a clear message rather than a broken result if Welch's ANOVA is picked manually despite a zero-variance group. Reports a full ANOVA table, eta-squared or epsilon-squared effect size, and a bar chart with 95% CI error bars plus per-group histograms. Post-hoc pairwise comparisons (Tukey's HSD, Games–Howell, Dunn's test) aren't implemented yet.
- **GLM** — logistic regression (binary 0/1 outcome), Poisson regression (count outcome), or Poisson regression for binary outcomes (relative risk, with robust "sandwich" standard errors in place of odds ratio) on any number of predictors (add/remove as needed), fit by Newton–Raphson (IRLS) to the exact log-likelihood. Each predictor is typed as continuous (used as-is), ordinal (converted to an equally-spaced numeric score in a specified or auto-detected category order), or nominal (dummy-coded into k−1 indicator columns against a reference category) — the model is fit on whichever mix of these results. Reports a coefficient table with Wald tests and the odds ratio / incidence rate ratio / relative risk with 95% CI for every term, a likelihood ratio test against the intercept-only model (df scaling with the number of coefficients added), and McFadden's pseudo-R², alongside a fitted-curve plot when there's exactly one continuous predictor. Checks events-per-variable (per coefficient) for both binary-outcome models and overdispersion for count Poisson regression — when the Poisson count data are overdispersed, standard errors are automatically widened (quasi-Poisson adjustment) rather than left overconfident. Flags non-convergence (perfect/near-perfect separation) and fitted probabilities above 1 (a known quirk of the binary-outcome Poisson method) rather than reporting either as if nothing were wrong. Interaction terms and negative-binomial regression aren't implemented yet.
- **Meta-Analysis** — pools an arbitrary number of 2×2 studies (added manually, sent from the Contingency table tab, imported from CSV by file picker or drag-and-drop, or loaded as illustrative sample data), in an editable table with per-row validation. Toggle between odds ratio, risk ratio, or risk difference, and between a fixed-effect model (Mantel–Haenszel for OR/RR, inverse-variance for RD) or DerSimonian–Laird random effects, with an optional Hartung–Knapp–Sidik–Jonkman (HKSJ) adjustment that widens the CI and switches to a t-distribution. Studies with a zero cell get the standard 0.5 continuity correction, flagged in the table. Reports Cochran's Q, I², and τ², a publication-style SVG forest plot (study squares sized by model weight, pooled diamond, log or linear x-axis) and funnel plot with pseudo-95% limits and Egger's test for asymmetry, both exportable as SVG/PNG, plus CSV export of the study list. REML, subgroup analysis, meta-regression, and trim-and-fill aren't implemented yet.
- **ML/NN** — upload a CSV (drag-and-drop, paste, or an illustrative sample clinical dataset), assign each column a role (Feature, Target, or Meta/ID to ignore) and a data type (numeric, categorical, or binary) with auto-detected defaults, then train a model entirely client-side. A blank cell in a numeric column is mean-imputed, not silently read as zero; a blank target value excludes that row (with an on-screen count) rather than breaking evaluation. Numeric features are standardized and nominal/binary ones are dummy-coded against a reference category (k−1 columns, matching the GLM tab, so a design matrix with an intercept never becomes collinear); the task (binary classification, multi-class classification, or regression) is inferred from the target's type. Model choices: logistic/softmax regression — every case (binary, multi-class, and regression) fit exactly, by the same Newton–Raphson engine as the GLM tab for the two classification cases and by closed-form OLS for regression, so there are no learning-rate or iteration-count hyperparameters to set — plus decision tree, random forest (bootstrap-aggregated trees that also restrict each split to a random √p/p⁄3-sized feature subset, per Breiman's original recipe, rather than bootstrapping alone), and k-NN (its predicted probabilities correctly renormalize if k is set larger than the training set). Or a configurable multilayer perceptron trained with TensorFlow.js (loaded from a CDN only when you train one), with adjustable hidden layers, neuron counts, activation function, learning rate, and epochs, plus a live training/validation loss curve — verified to train correctly in-browser with no tensor-memory leak across repeated or batch predictions. The train/test split (and, for the neural network, its internal training/validation split) is stratified by class for classification tasks, so a rare class's proportion is preserved on both sides rather than left to chance. Evaluates on a held-out test set — accuracy, and macro-averaged precision/recall/F1 (labeled as such: each computed per class, then averaged with every class weighted equally) — plus a confusion-matrix heatmap and an ROC curve with AUC for classification (computed with proper tie-grouping, so repeated predicted probabilities — common with tree/forest/k-NN models — don't distort the curve); R², MSE, MAE, and an actual-vs-predicted plot for regression. A live prediction playground generates an input per feature (sliders for numeric, dropdowns for categorical) and shows the predicted class with an animated confidence bar and full probability breakdown, or the point estimate for regression; a batch mode scores an uploaded CSV (flagging any category value not seen during training rather than silently encoding it as the reference level) and offers the result with appended prediction/confidence columns as a download. Support vector machines, cross-validation, and feature importance aren't implemented yet.
  A second, independent **unsupervised learning (clustering)** module sits below it with its own data upload and feature selection: k-means clustering (k-means++ initialization, 10–15 random restarts keeping the lowest-inertia run) groups rows by similarity with no target needed. The ideal number of groups is suggested automatically by scanning k = 2 to 10 and picking the highest average silhouette score (shown as a chart, and overridable with a slider) — both the k-means engine and the silhouette scoring were validated against synthetic data with a known cluster structure (100% purity recovery, and a hand-verified silhouette calculation) before being wired in. Reports group sizes, a group profile table (mean/mode feature values per group), and a 2D scatter plot with centroids when exactly two numeric features are used. A live playground assigns a single new point to its nearest group by distance, and a batch mode assigns a group to every row of an uploaded CSV.

Open `index.html` in a browser, or serve the repo with GitHub Pages — no build step, npm, or backend. The ML/NN tab's neural network loads TensorFlow.js from a CDN on first use; every other feature, including the ML tab's classical models, has no external dependency.
