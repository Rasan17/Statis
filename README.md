# Statis

A single-page calculator with eight tabs:

- **Contingency table** — chi-squared test (with optional Yates' continuity correction), Fisher's exact test, and odds ratio / relative risk with 95% confidence intervals. An "Add to Meta-Analysis" button sends the current 2×2 table straight into the Meta-Analysis tab's study list.
- **T-test** — independent-samples or paired t-tests, with a Shapiro–Wilk normality check, per-group histograms, and (for independent samples) a Levene's test for equal variance. A Method selector defaults to Auto, picking Student's t-test, Welch's t-test, Mann–Whitney U, or the Wilcoxon signed-rank test based on those checks — or you can override it manually. Also shows a bar chart of group means with 95% CI error bars, a full descriptive stats table (mean, SD, SEM, CI, median, mode, quartiles, IQR), and a Cohen's d / rank-biserial r effect size with an interpretation guide.
- **Correlation** — a scatter plot, Shapiro–Wilk normality checks on X and Y, and a linearity (curvature) test, feeding an Auto method selector that picks Pearson's r or Spearman's rank correlation. Kendall's tau is available as a manual third option, suggested (not auto-applied) when the sample is small and either variable has tied values. Also fits an OLS linear regression, with Breusch–Pagan and residual-normality diagnostics that flag when the regression's own assumptions don't hold.
- **Survival** — Kaplan–Meier estimation for one group or a two-group comparison, from pasted or CSV-uploaded time/event/group data with column mapping, row-level validation, and a data-quality summary. Reports the survival curve (with Greenwood log-log confidence bands and censoring ticks), median survival with 95% CI (explicitly "not reached" when applicable, never approximated), a two-sided log-rank test for two groups, an inspectable life table, and export to SVG/PNG/CSV, clipboard, and a generated Methods-and-Results paragraph. No hazard ratio is computed — that needs a Cox model, which isn't implemented yet.
- **ANOVA** — an arbitrary number of groups (add/remove as needed), with per-group Shapiro–Wilk normality checks, histograms, and a k-group Levene's test. A Method selector defaults to Auto, which picks standard one-way ANOVA (normal groups, equal variances), Welch's ANOVA (normal groups, unequal variances), a Box–Cox transform followed by Welch's ANOVA (non-normal groups that a transform fixes), or the Kruskal–Wallis test (non-normal groups a transform can't fix) — all four are also selectable manually. Reports a full ANOVA table, eta-squared or epsilon-squared effect size, and a bar chart with 95% CI error bars plus per-group histograms. Post-hoc pairwise comparisons (Tukey's HSD, Games–Howell, Dunn's test) aren't implemented yet.
- **GLM** — logistic regression (binary 0/1 outcome), Poisson regression (count outcome), or Poisson regression for binary outcomes (relative risk, with robust "sandwich" standard errors in place of odds ratio) on any number of predictors (add/remove as needed), fit by Newton–Raphson (IRLS) to the exact log-likelihood. Each predictor is typed as continuous (used as-is), ordinal (converted to an equally-spaced numeric score in a specified or auto-detected category order), or nominal (dummy-coded into k−1 indicator columns against a reference category) — the model is fit on whichever mix of these results. Reports a coefficient table with Wald tests and the odds ratio / incidence rate ratio / relative risk with 95% CI for every term, a likelihood ratio test against the intercept-only model (df scaling with the number of coefficients added), and McFadden's pseudo-R², alongside a fitted-curve plot when there's exactly one continuous predictor. Checks events-per-variable (per coefficient) for both binary-outcome models and overdispersion for count Poisson regression — when the Poisson count data are overdispersed, standard errors are automatically widened (quasi-Poisson adjustment) rather than left overconfident. Flags non-convergence (perfect/near-perfect separation) and fitted probabilities above 1 (a known quirk of the binary-outcome Poisson method) rather than reporting either as if nothing were wrong. Interaction terms and negative-binomial regression aren't implemented yet.
- **Meta-Analysis** — pools an arbitrary number of 2×2 studies (added manually, sent from the Contingency table tab, imported from CSV by file picker or drag-and-drop, or loaded as illustrative sample data), in an editable table with per-row validation. Toggle between odds ratio, risk ratio, or risk difference, and between a fixed-effect model (Mantel–Haenszel for OR/RR, inverse-variance for RD) or DerSimonian–Laird random effects, with an optional Hartung–Knapp–Sidik–Jonkman (HKSJ) adjustment that widens the CI and switches to a t-distribution. Studies with a zero cell get the standard 0.5 continuity correction, flagged in the table. Reports Cochran's Q, I², and τ², a publication-style SVG forest plot (study squares sized by model weight, pooled diamond, log or linear x-axis) and funnel plot with pseudo-95% limits and Egger's test for asymmetry, both exportable as SVG/PNG, plus CSV export of the study list. REML, subgroup analysis, meta-regression, and trim-and-fill aren't implemented yet.
- **ML/NN** — upload a CSV (drag-and-drop, paste, or an illustrative sample clinical dataset), assign each column a role (Feature, Target, or Meta/ID to ignore) and a data type (numeric, categorical, or binary) with auto-detected defaults, then train a model entirely client-side. Numeric features are standardized and categorical/binary ones are encoded automatically; the task (binary classification, multi-class classification, or regression) is inferred from the target's type. Model choices: logistic/softmax regression and decision tree/random forest/k-NN, all hand-written and validated in this app (logistic regression cross-checked against the GLM tab's Newton–Raphson engine and against closed-form OLS); or a configurable multilayer perceptron trained with TensorFlow.js (loaded from a CDN only when you train one), with adjustable hidden layers, neuron counts, activation function, learning rate, and epochs, plus a live training/validation loss curve. Evaluates on a held-out test set — accuracy/precision/recall/F1, a confusion-matrix heatmap, and an ROC curve with AUC for classification; R², MSE, MAE, and an actual-vs-predicted plot for regression. A live prediction playground generates an input per feature (sliders for numeric, dropdowns for categorical) and shows the predicted class with an animated confidence bar and full probability breakdown, or the point estimate for regression; a batch mode scores an uploaded CSV and offers the result with appended prediction/confidence columns as a download. Support vector machines, cross-validation, feature importance, and stratified splitting aren't implemented yet.

Open `index.html` in a browser, or serve the repo with GitHub Pages — no build step, npm, or backend. The ML/NN tab's neural network loads TensorFlow.js from a CDN on first use; every other feature, including the ML tab's classical models, has no external dependency.
