# Statis

A single-page calculator with nine tabs:

- **Contingency table** — chi-squared test (with optional Yates' continuity correction), Fisher's exact test, and odds ratio / relative risk with 95% confidence intervals — reported as "not estimable" rather than a fabricated number when a whole row or column is empty. Counts are validated to whole numbers ≥ 0, with an invalid cell clearly flagged rather than silently coerced to 0. An "Add to Meta-Analysis" button sends the current 2×2 table straight into the Meta-Analysis tab's study list.
- **Pivot** — upload or paste a CSV/TSV, assign each column's scale of measurement (continuous, ordinal, or nominal, auto-detected from the data), and get a single-variable summary (mean/SD/SEM/median/IQR with a mini histogram for continuous variables, downloadable as SVG/PNG; a frequency table with a mini bar chart, likewise downloadable, and cumulative counts for ordinal, for categorical ones) plus a filterable row × column cross-tabulation (toggle any category on/off, and switch cell values between count, % of row, % of column, and % of total). Automatically picks and runs the appropriate association test — Pearson's chi-squared (with Yates' correction shown for 2×2), Fisher's exact test for a 2×2 table with small expected counts (the same validated engine as the Contingency table tab, so both always agree), or the Fisher–Freeman–Halton exact test (the same idea generalized to any table size) — based on Cochran's criteria, and reports Cramér's V plus odds ratio / relative risk for 2×2 tables. The Fisher–Freeman–Halton implementation is validated in this app by confirming it exactly reproduces the 2×2 Fisher's exact result; it falls back to the chi-squared approximation (clearly labeled) for tables too large to enumerate exactly in the browser, and its repeated log-factorial calls are memoized for speed.
- **T-test** — independent-samples or paired t-tests, with a Shapiro–Wilk normality check (validated for, and restricted to, 3–5,000 observations — outside that range a value is deliberately not shown rather than presenting an unreliable approximation), per-group histograms, and (for independent samples) a Levene's test for equal variance. A Method selector defaults to Auto, picking Student's t-test, Welch's t-test, Mann–Whitney U, or the Wilcoxon signed-rank test based on those checks — or you can override it manually. For small samples (fewer than 50 per group, or fewer than 50 non-zero paired differences — the same cutoff R's `wilcox.test` uses), Mann–Whitney and Wilcoxon report an exact permutation p-value, computed from the full rank distribution rather than the normal approximation, and the results panel labels which one is shown. Also shows a bar chart of group means with 95% CI error bars, a full descriptive stats table (mean, SD, SEM, CI, median, mode, quartiles, IQR), and an effect size with an interpretation guide: Cohen's d for the t-tests, rank-biserial correlation for Mann–Whitney U (signed so a positive value means group A tends larger, matching the displayed mean difference), and — a distinct, non-interchangeable statistic, labeled as such — z⁄√n for the Wilcoxon signed-rank test. The bar chart and each group's histogram can be downloaded individually as SVG or PNG.
- **Correlation** — a scatter plot, Shapiro–Wilk normality checks on X and Y, and a curvature test (a nested quadratic-vs-linear F-test, fit via QR decomposition rather than the normal equations for numerical stability with large or skewed x-values), feeding an Auto method selector that picks Pearson's r or Spearman's rank correlation. Kendall's tau is available as a manual third option, suggested (not auto-applied) when the sample is small and either variable has tied values. Also fits an OLS linear regression — reporting 95% confidence intervals for both the slope and intercept, not just the slope's p-value — with a single-predictor Breusch–Pagan diagnostic and residual-normality checks that flag when the regression's own assumptions don't hold. The scatter plot is downloadable as SVG or PNG.
- **Survival** — Kaplan–Meier estimation for one group or a two-group comparison, from pasted or CSV-uploaded time/event/group data with column mapping, row-level validation, and a data-quality summary. Reports the survival curve (with Greenwood log-log confidence bands and censoring ticks — left unreported, rather than a fabricated zero-width interval, at the boundary where no one remains at risk), median survival with 95% CI (explicitly "not reached" when applicable, never approximated), a two-sided log-rank test for two groups (a single O(n log n) sweep over the pooled event times, so it stays responsive on registry-sized datasets), an inspectable life table, and export to SVG/PNG/CSV, clipboard, and a generated Methods-and-Results paragraph. No hazard ratio is computed — that needs a Cox model, which isn't implemented yet.
- **ANOVA** — an arbitrary number of groups (add/remove as needed), with per-group Shapiro–Wilk normality checks, histograms, and a k-group Levene's test. A Method selector defaults to Auto, which picks standard one-way ANOVA (normal groups, equal variances), Welch's ANOVA (normal groups, unequal variances), a Box–Cox transform followed by Welch's ANOVA (non-normal groups that a transform fixes), or the Kruskal–Wallis test (non-normal groups a transform can't fix, or any group with zero variance — every value identical — which Welch's ANOVA can't handle since it weights each group by 1/variance) — all four are also selectable manually, with a clear message rather than a broken result if Welch's ANOVA is picked manually despite a zero-variance group. Reports a full ANOVA table, eta-squared (standard ANOVA only — Welch's adjusted denominator doesn't partition variance the same way, so it's left unreported there rather than shown as a misleading number) or epsilon-squared effect size, and a bar chart with 95% CI error bars plus per-group histograms, all downloadable as SVG/PNG. Post-hoc pairwise comparisons (Tukey's HSD, Games–Howell, Dunn's test) aren't implemented yet.
- **GLM** — logistic regression (binary 0/1 outcome), Poisson regression (count outcome), or Poisson regression for binary outcomes (relative risk, with robust "sandwich" standard errors in place of odds ratio) on any number of predictors (add/remove as needed), fit by Newton–Raphson (IRLS) to the exact log-likelihood, with step-halving (as in R's `glm.fit`) so a step that would decrease the likelihood is shrunk rather than allowed to overshoot, and starting values set at the null-model estimate rather than zero. Each predictor is typed as continuous (used as-is), ordinal (converted to an equally-spaced numeric score in a specified or auto-detected category order), or nominal (dummy-coded into k−1 indicator columns against a reference category) — the model is fit on whichever mix of these results. Reports a coefficient table with Wald tests (labeled as such, alongside a caveat that Wald CIs can be unreliable with sparse data or near-separation) and the odds ratio / incidence rate ratio / relative risk with 95% CI for every term, a likelihood ratio test against the intercept-only model (df scaling with the number of coefficients added), and McFadden's pseudo-R², alongside a downloadable fitted-curve plot when there's exactly one continuous predictor. Checks events-per-variable (per coefficient) for both binary-outcome models and overdispersion for count Poisson regression — when the Poisson count data are overdispersed, standard errors are automatically widened (quasi-Poisson adjustment) rather than left overconfident. Flags non-convergence (perfect/near-perfect separation) and fitted probabilities above 1 for the binary-outcome Poisson method (a model-diagnostic warning worth checking, not a cosmetic quirk) rather than reporting either as if nothing were wrong. Interaction terms and negative-binomial regression aren't implemented yet.
- **Meta-Analysis** — pools an arbitrary number of 2×2 studies (added manually, sent from the Contingency table tab, imported from CSV by file picker or drag-and-drop, or loaded as illustrative sample data), in an editable table with per-row validation. Toggle between odds ratio, risk ratio, or risk difference, and between a fixed-effect model (Mantel–Haenszel for OR/RR — computed from the raw cell counts with no continuity correction, matching RevMan, Stata, and R's metafor/meta, so it stays well-behaved with sparse or zero-cell studies — or inverse-variance for RD) or DerSimonian–Laird random effects, with an optional Hartung–Knapp–Sidik–Jonkman (HKSJ) adjustment that widens the CI and switches to a t-distribution. Studies with a zero cell get a commonly used 0.5 continuity correction for their own OR/RR and for inverse-variance pooling, flagged in the table. Reports Cochran's Q, I², and τ², a publication-style SVG forest plot (study squares sized by model weight, pooled diamond, log or linear x-axis) and funnel plot with pseudo-95% limits and Egger's test for asymmetry, both exportable as SVG/PNG, plus CSV export of the study list (study names are escaped against CSV formula injection on both export and re-import). REML, subgroup analysis, meta-regression, and trim-and-fill aren't implemented yet.
- **ML/NN** — upload a CSV (drag-and-drop, paste, or an illustrative sample clinical dataset), assign each column a role (Feature, Target, or Meta/ID to ignore) and a data type (numeric, categorical, or binary) with auto-detected defaults, then train a model entirely client-side. A blank cell in a numeric column is mean-imputed, not silently read as zero; a blank target value excludes that row (with an on-screen count) rather than breaking evaluation. Numeric features are standardized and nominal/binary ones are dummy-coded against a reference category (k−1 columns, matching the GLM tab, so a design matrix with an intercept never becomes collinear); the task (binary classification, multi-class classification, or regression) is inferred from the target's type. Model choices: logistic/softmax regression — every case (binary, multi-class, and regression) fit exactly, by the same step-halving Newton–Raphson engine as the GLM tab for the two classification cases and by closed-form OLS for regression, so there are no learning-rate or iteration-count hyperparameters to set — plus decision tree, random forest (bootstrap-aggregated trees that also restrict each split to a random √p/p⁄3-sized feature subset, per Breiman's original recipe, rather than bootstrapping alone), and k-NN (its predicted probabilities correctly renormalize if k is set larger than the training set). Or a configurable multilayer perceptron trained with TensorFlow.js (loaded from a CDN only when you train one), with adjustable hidden layers, neuron counts, activation function, learning rate, and epochs, plus a live, downloadable training/validation loss curve — verified to train correctly in-browser with no tensor-memory leak across repeated or batch predictions, and stops immediately with a clear message (naming the epoch) if the loss ever diverges to NaN or infinity, rather than running out the remaining epochs on an already-broken model. An optional random seed (blank = a fresh result every run) makes the stratified train/test split and every model's own randomness — random forest's bootstrap samples and per-split feature subsets, and the neural network's weight initialization and internal validation split — exactly reproducible from the same data and settings. The train/test split (and, for the neural network, its internal training/validation split) is stratified by class for classification tasks, so a rare class's proportion is preserved on both sides rather than left to chance. Evaluates on a held-out test set — accuracy, and macro-averaged precision/recall/F1 (labeled as such: each computed per class, then averaged with every class weighted equally) — plus a downloadable confusion-matrix heatmap and ROC curve with AUC for classification (computed with proper tie-grouping, so repeated predicted probabilities — common with tree/forest/k-NN models — don't distort the curve); R², MSE, MAE, and a downloadable actual-vs-predicted plot for regression. A live prediction playground generates an input per feature (sliders for numeric, dropdowns for categorical) and shows the predicted class with an animated confidence bar and full probability breakdown, or the point estimate for regression; a batch mode scores an uploaded CSV (flagging any category value not seen during training rather than silently encoding it as the reference level) and offers the result with appended prediction/confidence columns as a download. Support vector machines, cross-validation, and feature importance aren't implemented yet.
  A second, independent **unsupervised learning (clustering)** module sits below it with its own data upload and feature selection, and a choice of four algorithms — each validated against synthetic data with a known group structure before being wired in: k-means (the greedy k-means++ initialization scikit-learn uses — several candidate centers considered at each step, keeping whichever most reduces total potential, rather than just one — with 10–15 random restarts keeping the lowest-inertia run), hierarchical clustering with Ward's linkage (agglomerative merging via the Lance–Williams update, deterministic, no random restarts), a Gaussian mixture model fit by expectation-maximization (soft, probabilistic groups that can be elongated or correlated rather than only round, keeping the best of 5 random-start fits by log-likelihood), and DBSCAN (density-based — finds groups of any shape and flags outliers as noise rather than forcing them into a group, with no target number of groups to choose; disabled above 8,000 rows, since its memory use can grow with the square of the row count). For the three algorithms that take a group count, the ideal number is suggested automatically by scanning k = 2 to 10 and picking the highest average silhouette score (shown as a downloadable chart, and overridable with a slider); DBSCAN instead exposes its radius (eps) and minimum-points parameters, and its silhouette score (when shown) excludes noise points. Hierarchical clustering's final fit is disabled above 2,000 rows, since its cost grows with the cube of the row count. An optional random seed (shared with the ML tab's field) makes k-means and Gaussian-mixture results exactly reproducible. Reports group sizes, a group profile table (mean/mode feature values per group, with DBSCAN's noise points shown as their own row), and a downloadable 2D scatter plot with centroids (and noise points visually distinguished) when exactly two numeric features are used. A live playground assigns a single new point — by nearest centroid for k-means/hierarchical, by posterior-probability argmax (with the full breakdown shown) for the Gaussian mixture, or, for DBSCAN (labeled as a disclosed heuristic, since DBSCAN itself defines no rule for a new point), by the nearest in-cluster training point within eps, preferring a core point over a border point when both are in range, else flagged as noise — and a batch mode applies the same rule to every row of an uploaded CSV.

Every chart across every tab — bar charts, histograms, scatter plots, fitted curves, the confusion matrix, ROC and loss curves, and the cluster scatter and silhouette charts — can be downloaded individually as SVG or a print-resolution PNG, rendered on a plain white background regardless of the app's own dark theme.

Open `index.html` in a browser, or serve the repo with GitHub Pages — no build step, npm, or backend, and no analytics or telemetry of any kind. The ML/NN tab's neural network loads TensorFlow.js from a CDN on first use, and Google Fonts are loaded for the page's typefaces; every other feature, including the ML tab's classical models, has no external dependency, and no user data ever leaves the browser.
