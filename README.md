# Fourfold

A single-page calculator for 2×2 contingency tables: chi-squared test (with optional Yates' continuity correction), Fisher's exact test, and odds ratio / relative risk with 95% confidence intervals.

Open `index.html` in a browser, or serve the repo with GitHub Pages — no build step or dependencies.
